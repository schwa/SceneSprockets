# ``SceneSprocketsGizmos``

Transform gizmos and selection outlines for `SceneView`.

## Overview

A ``TransformGizmo`` is a `SceneViewManipulator`. Set it as the view's manipulator, and it draws handles that move, rotate and scale the selected node. ``SelectionOutline`` draws an outline around the selected nodes.
