# ``SceneSprocketsGizmos``

Transform gizmos and selection outlines for `SceneView`.

## Overview

A ``TransformGizmo`` is a `ViewManipulator`. When you set it as the manipulator of the view, it draws handles that move, rotate and scale the selected node. ``SelectionOutline`` draws an outline around the selected nodes.
