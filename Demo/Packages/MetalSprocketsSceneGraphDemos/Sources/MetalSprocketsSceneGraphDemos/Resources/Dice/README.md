# Dice assets

The dice themselves have no assets: DiceGeometry builds the meshes, number atlases and normal maps in code.

## Tray

`DarkWood-*.jpg`: [Dark Wood](https://polyhaven.com/a/dark_wood) from Poly Haven, CC0. By Dimitrios Savva
(photography), Dario Barresi (baking) and Rico Cilliers (tiling). Resized to 1024×1024; `MetallicRoughness` has the
roughness map in green and zero metalness in blue.
